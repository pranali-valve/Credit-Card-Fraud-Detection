# 💳 Credit Card Fraud Detection using Machine Learning

## 📌 Project Overview

This project detects fraudulent credit card transactions using **Logistic Regression**. It is a binary classification problem where the model predicts whether a transaction is genuine or fraudulent.

---

## 🎯 Objective

Build a Machine Learning classification model to identify fraudulent credit card transactions.

---

## 🛠 Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

---

## 📂 Dataset Features

* Time
* V1–V28 (anonymized features)
* Amount
* Class (0 = Genuine, 1 = Fraud)

---

## 🔄 Workflow

1. Import Libraries
2. Load Dataset
3. Explore Dataset
4. Check Class Distribution
5. Split Features and Target
6. Train-Test Split
7. Train Logistic Regression Model
8. Make Predictions
9. Evaluate Model
10. Save Model
